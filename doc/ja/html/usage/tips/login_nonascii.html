ユーザ名またはパスワードに非 ASCII 文字を使用する場合の注意

SSH 接続

SSH プロトコルでは、ユーザ名およびパスワードは UTF-8 で送信されることが RFC 4252 により規定されています。
Tera Term は非 ASCII 文字を含むユーザ名やパスワードを UTF-8 で送信しますが、接続先の SSH サーバが UTF-8 を正しく処理できない場合、SSH 認証に失敗します。
また、SSH 接続に関係する処理（PAM、SSSD、LDAP など）の実装によっては、ロケール依存の文字コードでパスワードを処理する場合があり、非 ASCII 文字を含むパスワードが正しく認識されないことがあります。

Telnet 接続

Telnet プロトコルは本来 ASCII を前提としており、ユーザ名およびパスワードに非 ASCII 文字が使用されることは想定されていません。
Tera Term は非 ASCII 文字を含むユーザ名およびパスワードを送信する際、設定された送信文字コードに従ってエンコードを行いますが、接続先の Telnet サーバが同じ文字コードを使用していない場合、認証に失敗する可能性があります。
