ttlaunch

Tera Term 内で各種 shell を起動するためのランチャーです。

Cygwin, MSYS2 または Git for Windows がインストールされた環境で利用できます。 WSL と Windows の shell も CygTerm+ を経由して起動するため、これらのいずれかが必要です。

Tera Term のインストーラーで CygTerm+ をインストールし、 追加タスク「コンテキストメニューに "Tera Term &Here" (ttlaunch) を追加する」を選択すると、 エクスプローラーのコンテキストメニュー(右クリックで表示されるメニュー)に "Tera Term Here" が追加されます。 選択すると起動できる shell の一覧が表示されます。

起動可能 shell

  • Cygwin
  • MSYS2 (MSYS, MinGW x32, MinGW x64, UCRT64, CLANG64, CLANGARM64)
  • Git Bash
  • WSL
  • Windows の shell (コマンドプロンプト, Windows PowerShell, PowerShell 7)
