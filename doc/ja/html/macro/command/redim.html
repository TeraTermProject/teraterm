redim

ユーザー変数の配列サイズを変更する。(バージョン5.8.0以降) 
redim <array> <size> ['Preserve']

パラメータ

配列 <array>
整数配列または文字列配列。
整数 <size>
配列サイズ(1 ～ 65536)。
文字列 'Preserve'
省略可能。省略時は既存のデータは初期化される。
'Preserve' を指定すると既存のデータを保持したまま配列サイズを変更する。
指定された配列サイズが元のサイズより小さい場合は、縮小部分の要素を削除する。

返り値

なし

解説

整数配列または文字列配列の配列サイズを変更する。
システム変数及び未使用状態の変数には使用できない。

例

strdim strarray 1                 ; Array declaration is required.

for size 1 65536
  redim strarray size 'Preserve'  ; Resize the array while preserving existing data.
  index = size - 1
  sprintf2 title 'element : %d' index
  inputbox 'Input finished without data.' title
  strcompare inputstr ''
  if result = 0 then
    goto show_listbox
  endif
  strarray[index] = inputstr
next

:show_listbox
listbox 'Input data' 'strarray' strarray
