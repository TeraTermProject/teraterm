delvar

指定されたユーザー変数を未使用状態に戻す。(バージョン5.8.0以降) 
delvar <variable1> [<variable2> ...]

パラメータ

変数 <variable1>
未使用状態に戻すユーザー変数
変数 [<variable2> ...]
未使用状態に戻すユーザー変数。省略可能。複数指定可。

返り値

なし

解説

ユーザー変数の型、値、配列サイズを消去し、未使用状態に戻す。
システム変数及び未使用状態の変数には使用できない。
ユーザー変数の型および値は初めて値が代入されたときに決まる。いったん型が決まると違う型の値を代入することはできない。
delvar を使用すると指定されたユーザー変数が未使用状態に戻り、別の型の値の代入が可能になる。

例

strdim array 10
array[0] = 'String Array'
var = 'Character string'

delvar array var

intdim array 10
array[0] = 12345  ; Integer Array
var = 999         ; Integer
