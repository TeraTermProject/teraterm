delvar

Restores the specified user variable to the unused state. (version 5.8.0 or later) 
delvar <variable1> [<variable2> ...]

Parameters

Variable <variable1>
User variable to be restored to the unused state.
Variable [<variable2> ...]
User variables to be restored to the unused state. Optional. Multiple allowed.

Return Value

None.

Remarks

Removes the type, value, and array size of the user variable and resets it to the unused state.
This command cannot be used with system variables or unused variables.
The type of a variable is determined when a value is assigned to it for the first time. Once the type of the variable is determined, values of a different type cannot be assigned to it.
By using delvar, the specified user variable is restored to the unused state, allowing a value of a different type to be assigned again.

Example

strdim array 10
array[0] = "String Array"
var = "Character string"

delvar array var

intdim array 10
array[0] = 12345  ; Integer Array
var = 999         ; Integer
