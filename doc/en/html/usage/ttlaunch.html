ttlaunch

ttlaunch is a launcher to start various shells in Tera Term.

It can be used when Cygwin, MSYS2 or Git for Windows is installed. WSL and the Windows shells are also started via CygTerm+, so one of them is required.

Running ttlaunch -setup opens the settings dialog, where ttlaunch can be added to the Explorer context menu (the menu shown by right-clicking). The installer does not add it. It is registered for the current user (HKEY_CURRENT_USER), so administrator rights are not required. Selecting "Open in Tera Term" in the context menu shows a list of shells that can be started.

Available shells

  • Cygwin
  • MSYS2 (MSYS, MinGW x32, MinGW x64, UCRT64, CLANG64, CLANGARM64)
  • Git Bash
  • WSL
  • Windows shells (Command Prompt, Windows PowerShell, PowerShell 7)
